一、坐标轴 ↔ 稳定性 ↔ 谁负责

最高频，一错串三题
必背
三轴 ↔ 稳定性 ↔ 责任部件（完整对应表）
绕什么轴稳定性名称别称谁负责
横轴纵向稳定性俯仰水平尾翼
立轴航向稳定性方向垂直尾翼
纵轴横向稳定性滚转机翼上反角

口诀：横轴管俯仰（纵向）、立轴管偏航（航向/方向）、纵轴管滚转（横向）。横对纵、立对角、纵对滚——轴名和稳定名是"交叉"的，这是最容易记反的地方。

  • 向右压副翼杆 → 左翼升力大于右翼（飞机右滚）。 id 909

必背
副翼"逆偏转"与协调转弯
  • 副翼转弯时，外侧机翼阻力大（外侧副翼下偏）。
  • 修正逆偏转：副翼往哪压转弯，方向舵就往哪蹬。右转弯→方向舵右偏；左转弯→方向舵左偏。
  • 坡度转弯同时踩方向舵 → 协调转弯，减小转弯半径并减少侧滑。
  • 转弯向心力 = 升力的水平分力。
题库：957 956 958 1280 935
必背
侧滑回正 · 重心影响 · 匹配关系
  • 具静稳定性飞机向左侧滑 → 机头向左转（垂尾风标效应，机头追来流）。 id 1105
  • 重心位置影响的是 纵向稳定性和航向稳定性（不是"只对纵向"、不是"横向"）。 id 1114
  • 横向与航向、纵向与航向之间 → 必须匹配适当（都不是"互相独立"）。 id 1109 / 1116
  • 滚转平衡中主要力矩 = 机翼升力力矩。 id 1121

二、失速与迎角

考最多，最爱埋反直觉答案
必背
失速的本质：只有一个原因

核心：失速的直接原因 / 唯一原因 = 迎角超过临界迎角。跟速度大小没有直接关系——"速度太小导致失速"是错的。

  • 失速的直接原因 → 迎角过大。 id 962
  • 飞机失速的原因 → 迎角超过临界迎角。 id 927
  • "失速"定义 → 飞机以大于临界迎角飞行。 id 997
  • 临界迎角 = 升力系数最大时的迎角。 id 998
  • 机理：迎角达临界值 → 机翼上表面附面层大部分分离。 id 1138
必背
失速速度：变大还是变小
条件变化失速速度id
放下襟翼减小905
水平转弯坡度增大增大928
平飞载重量越大越大1028
注意区分：放襟翼让失速速度变小（因为 CLmax 抬高），但临界迎角反而降低。这俩方向相反，别混。（详见"襟翼"考点，id 1158）
必背
失速处置与现象
  • 出现失速 → 立即推杆到底（推杆减小迎角）。不是拉杆、不是蹬舵。 id 959
  • 接近失速 → 操纵迟钝、操纵效率降低。 id 1096
  • 大迎角或高速飞行都可能失速；不能靠加大动力克服；亚音速不只有大迎角失速。 id 1148
  • 常规布局失速时 → 机翼向上的力与尾翼向下的力都降低。 id 899
必背
迎角与压力中心
  • 迎角定义 = 翼弦与相对气流的夹角（不是与水平面）。 id 919
  • 飞机上升 / 下降时，迎角都大于零。 id 926 / 929
  • 迎角增大 → 压力中心前移；迎角减小 → 后移。 id 932 / 931
  • 迎角超临界 → 升力系数迅速减小。 id 896
  • 临界迎角时 升力系数最大。 id 903
外部印证
襟翼增升：升力↑、临界迎角↓

口诀：后缘襟翼下偏 → 弯度增大 → 升力系数上限↑，同时后缘气流更早分离 → 临界迎角↓。

  • 主因是增大了机翼弯度（不是增面积、不是形成缝隙）。 id 1158
  • 增机翼面积 ↔ 增升力大小；缝隙是"开缝襟翼"特征，作用是延迟分离，方向相反。

题库：1178 1103 1133 1108
陷阱
"航向"和"方向"是同一个东西
  • 航向稳定性 = 方向稳定性 = 偏航稳定性，三个名字一个概念，都指绕立轴。 id 1133 / 1103 / 1108
  • 横向稳定性 = 滚转稳定性，绕纵轴，跟"航向"是两码事。 id 1110 / 1134
  • 别被"横向"两个字骗了——它不是"左右方向"的意思，而是"绕纵轴的滚转"。这是最容易栽的地方。

六、应试技巧

外部经验
经验
刷题顺序：按分值，不按书序
  • 法规空域优先（分值占比最高、数字考点集中、最好拿分）→ 其次飞行原理 → 气象 → 设备 → 应急。
  • 同一类题集中刷形成记忆惯性，不要一上来就整套模拟。
  • 错题单独收藏，刷 2 遍再做整套卷；考前 3 天只刷高频真题 + 错题。

来源：起航无人机服务平台（多家培训机构的刷题方法论基本一致）

经验
选择题排除法（考场提速）
  • 两个选项意思相反 → 答案必在二者之间，先排除另外两个。
  • 出现极端数字、极端操作（"立即猛拉""永远""完全"）→ 大概率排除。
  • 法规题优先选 提前报备、申请空域、终止飞行、降落 这类保守表述。
  • 描述最长、最严谨规范的选项，常常是官方标准答案话术。

来源：起航无人机服务平台 · 天途无人机培训

经验
绝对化词语陷阱

看到就警惕：必须、一定、所有、永久、任何、只需、绝不 → 大概率为错。
看到可优先考虑：应当、一般情况、视情况、评估后 → 大概率为对。

这是"经验规律"不是铁律，遇到具体知识点（比如"失速的直接原因是迎角过大"）还是要按题库逻辑走。别把技巧当答案。
